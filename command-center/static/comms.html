Comms tools

Morse code, emergency phrases in other languages, radio frequencies worth knowing, and the spelling alphabet. All of it works with no internet.

The bar flashes with the code, so it can be read across a room or signalled with the screen at night.

Tap it in

Hold the key short for a dot and long for a dash, at the speed set above. Pause to end a letter, pause longer to end a word. On a keyboard, use the space bar.

The code

Show the screen to the other person, or press Say if this device has a voice for that language. These are simple, common wordings and have not been checked by a native speaker.

Listening is always allowed. Transmitting has rules: FRS, MURS and CB need no licence, GMRS needs an FCC licence (one covers a family), and the ham bands need an amateur licence. These are United States channels.

Calling for help by voice

Life in danger: say "Mayday, Mayday, Mayday", then who you are, where you are, what is wrong, how many people, and what help you need. Say it slowly, then listen, then repeat.

Urgent but nobody is dying: start with "Pan-pan, Pan-pan, Pan-pan" and give the same details.
